# Make the Cutest Picture — Cream Kitten Hugging a Chick

Entry for the Make.fun "Make the cutest picture" bounty (cutest-picture-01).

A cream kitten with huge sparkling blue eyes, pink blush cheeks and a knitted mint scarf, sitting front-facing and hugging a tiny sleepy yellow chick. Soft cute 3D style, plain warm cream background, following the winning formula of the top entries: two tiny baby animals hugging, close-up, front-facing.
